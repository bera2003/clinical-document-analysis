# 🏥 Clinical Document Analysis System

A full-stack web application that uses **NLP (Natural Language Processing)** to analyze clinical documents, extract medical entities, and provide analytics dashboards.

---

## 🚀 Features

### 🔐 Authentication
- User **Sign Up & Login**
- JWT-based authentication
- Secure password hashing

### 📄 Clinical Document Processing
- Upload clinical documents (PDF / TXT)
- Extract:
  - Diseases
  - Symptoms
  - Medications
  - Patient details
- NLP-powered entity recognition

### 📊 Dashboard
- Upload documents
- View extracted entities
- Processing status
- Analytics & insights

---

## 🛠 Tech Stack

### Frontend
- **Next.js (App Router)**
- TypeScript
- Tailwind CSS
- Context API (Authentication)
- Shadcn UI

### Backend
- **FastAPI**
- SQLAlchemy
- MySQL
- JWT Authentication
- NLP (spaCy)
